# Dentistry — CRM для стоматологии

CRM-система для стоматологической клиники: расписание, пациенты, зубные формулы,
планы лечения, финансы, склад, омниканальные коммуникации, аналитика и
AI-ассистент. 

> **Демо:** `index.html` — полностью кликабельный интерактивный прототип
> (vanilla HTML/CSS/JS, без сборки). Деплоится на `dentaly.pages.dev`.

---

## Что в репозитории

| Файл | Назначение |
|------|-----------|
| **`index.html`** | Интерактивный мокап (эталон UI) — деплой-демо |
| **`TZ.md`** | Техническое задание: модули, экраны, роли, бизнес-правила |
| **`BACKEND_PLAN.md`** | Архитектура (Cloudflare Workers/D1/R2/DO), список API, cron |
| **`schema.sql`** | Модель данных D1 (SQLite) — все сущности |
| **`seed.sql`** | Демо-данные, отражающие мокап (Smile Studio) |
| **`DEPLOY.md`** | Развёртывание демо на Pages + бэкенда позже |
| **`CLAUDE.md`** | Контекст для сессий Claude Code |
| **`_headers`** | Заголовки безопасности для Cloudflare Pages |

**Порядок чтения для разработчика:** `TZ.md` → `index.html` (покликать) →
`schema.sql` → `BACKEND_PLAN.md`.

---

## Стек

- **Фронт:** vanilla JS + HTML + CSS, без билдера (Pages раздаёт статику как есть).
- **Бэкенд (план):** Cloudflare Workers (JS), D1 (SQLite), R2 (файлы), KV,
  Durable Objects (real-time, Hibernation API).
- **Документы:** .docx-шаблоны → PDF (Cloud Run, LibreOffice).
- **Интеграции:** Kaspi (QR/Red), WhatsApp Cloud API, Telegram Bot, SMS Mobizon,
  1С, Bitrix24, 3Shape, Straumann.
- **AI:** ассистент (GPT-4), надиктовка протокола (Whisper), скоринг рисков.

---

## Модули

Работа: **Дашборд · Расписание · Пациенты · Лечение**.
Бизнес: **Финансы · Склад · Коммуникации · Аналитика**. Плюс **Настройки** и
сквозной **AI-ассистент** (Dentaly AI).

Ключевая фича — **интерактивная зубная формула** (FDI 11–48) с состоянием по
поверхностям зуба и историей по каждому зубу, и **планы лечения** (план → визиты
→ этапы, 3 варианта Эконом/Стандарт/Премиум, график платежей).

Полное описание — в [`TZ.md`](TZ.md).
